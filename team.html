01 Abstract

This project presents an IoT-Based Solar Microgrid Energy Management System with Maximum Power Point Tracking (MPPT). The system integrates photovoltaic generation, MPPT charge control, battery storage and IoT-based monitoring to maximize solar utilization and deliver real-time energy intelligence. An ESP32 controller samples voltage, current, temperature and load data, publishes it over MQTT to a cloud database, and renders it on a live web dashboard with fault detection and AI-based energy forecasting.

02 Objectives

1 Maximize solar power extraction using MPPT algorithms.
2 Monitor voltage, current, power, temperature and battery state in real time.
3 Store telemetry in a cloud database and visualize it on a web dashboard.
4 Detect faults automatically and enable remote load control.
5 Predict solar generation and load demand using machine learning.
6 Improve system efficiency, reliability and battery longevity.

03 Methodology

Hardware was prototyped around a 1.28 kWp PV array feeding an MPPT charge controller and a 4.8 kWh LiFePO₄ battery bank. Sensor nodes stream telemetry to an ESP32, which publishes encrypted MQTT messages to a cloud broker. The dashboard subscribes to live channels, stores time-series history, runs fault-detection rules and hosts an AI forecasting pipeline that predicts generation from weather data. System performance was validated over multiple sunny, cloudy and shaded days.

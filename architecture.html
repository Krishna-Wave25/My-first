How Data Flows

From Sensor to Dashboard in Seconds

📡 Telemetry Pipeline

One seamless data journey

  • ✓ Sensors sample voltage, current, power, temperature and battery level
  • ✓ ESP32 aggregates readings and publishes over encrypted MQTT
  • ✓ Cloud gateway ingests, validates and stores time-series records
  • ✓ Dashboard subscribes and renders live charts and alerts
🔧 Control Pipeline

Two-way, responsive control

  • ✕ User toggles a load or mode from the dashboard
  • ✕ Command is sent to the IoT controller over MQTT
  • ✕ Relay module switches the circuit instantly
  • ✕ New state is confirmed and logged for the audit trail
